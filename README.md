A program that writes one line to `/output/entry.txt` (98 characters, inside the 160-character gate; 19 words, inside the 20-word cap): a fortune cookie for a crypto trader who has just been liquidated — the classic cookie promise of a tall, dark stranger, subverted into his margin call arriving at 3 a.m. to collect what he owes. Fortune voice up front, trading loss as the punchline, rueful rather than cruel.

## Run it

```sh
python3 main.py
```
